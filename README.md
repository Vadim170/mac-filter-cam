# mac-filter-cam

Фильтр для камеры на macOS: маски с рулеткой и дизеринг «как на чеке». Подключается
к Zoom, Meet, Teams и всему остальному через виртуальную камеру OBS.

Алгоритм перенесён из внутреннего проекта киоска Dodo (`kiosk-mobile-photo`), где гость
фотографируется, а снимок печатается на чеке: те же точки лица MediaPipe, то же
сглаживание поз, тот же Флойд–Стайнберг. Звук рычага и всё киосковое (стрим на киоск,
биты для термопринтера) выброшено.

## Установка на новом маке

```sh
brew install node
brew install --cask obs

git clone https://github.com/Vadim170/mac-filter-cam.git
cd mac-filter-cam
npm install
npm start
```

Всё. Откроется панель управления, поднимется OBS с доступом к камере, модель лица
скачается сама при первом запуске. Браузер один раз спросит доступ к камере — разрешите.

Осталось один раз собрать сцену в OBS:

1. **Источники** → **+** → **Браузер**.
2. URL `http://localhost:8787/?mode=obs`, размер 1280 × 720.
3. **Запустить виртуальную камеру** — кнопка справа внизу.
4. В Zoom: **Настройки** → **Видео** → камера **OBS Virtual Camera**.
   Zoom, запущенный раньше виртуальной камеры, её не увидит — перезапустите.

Дальше маски и настройки крутятся в панели, источник в OBS подхватывает всё сам.
Индикатор «OBS подключён» в панели показывает, что источник на связи.

### Если в источнике «Доступ к камере запрещён»

```sh
npm run obs
```

Команда перезапустит OBS так, как надо. Это самая частая осечка, и вот почему она бывает.

Встроенный браузер OBS по умолчанию отказывает странице в доступе к камере: устройства
он видит, но подтвердить запрос разрешения внутри источника некому — диалога там нет.
Свои аргументы OBS передаёт в CEF, поэтому лечится флагом
`--auto-accept-camera-and-microphone-capture`, и его добавляет `npm start`.

Загвоздка в том, что командную строку OBS читает только при старте. Стоит один раз
открыть OBS двойным кликом по иконке — и доступа к камере у него нет, хотя внешне всё
как обычно. `npm run obs` это распознаёт (флаг виден в аргументах процесса), закрывает
OBS и поднимает заново уже с доступом. `npm start` чужой OBS не трогает — вдруг там
идёт эфир, — а только предупреждает и советует эту команду.

Флаг действует только на источники «Браузер» внутри OBS и только на камеру с микрофоном;
захват экрана он не разрешает. Держите в браузерных источниках свои страницы, а не
случайные оверлеи из интернета.

### Команды

| Команда | Что делает |
| --- | --- |
| `npm start` | сервер + панель + OBS с доступом к камере |
| `npm run serve` | только сервер, ничего не открывает |
| `npm run obs` | перезапустить OBS с доступом к камере |
| `npm run cam` | запасное окно Chrome, если OBS не справился |

### Если картинки всё равно нет

Запасной путь — снимать не встроенный браузер OBS, а окно настоящего Chrome:

```sh
npm run cam
```

Откроется окно без вкладок и адресной строки — только картинка. Первый раз браузер
спросит доступ к камере, отдельный профиль это запомнит. Дальше в OBS:
**Источники** → **+** → **Захват окна** → это окно, и виртуальная камера как обычно.

Окно подгоняет себя под выбранное разрешение, так что чёрных полей по краям не будет.
Перекрывать его другими окнами можно — скрипт запускает Chrome с отключённым
торможением фоновых окон. А вот **сворачивать нельзя**: свёрнутое окно не снимается.

Обычная вкладка для этого не годится: в фоне браузер замораживает
`requestAnimationFrame`, и картинка в созвоне замрёт.

## Управление

| Что | Где |
| --- | --- |
| Следующая маска на барабане | тык по барабану |
| Крутить все три барабана | рычаг или пробел |
| Снять все маски | «снять все» |
| Размер точки дизеринга | ползунок, 1–5 пикселей |
| Контраст, яркость | ползунки |
| Зеркало | галка |
| Камера | список устройств |

**Камера** запоминается по названию, а не по идентификатору устройства. Идентификатор
браузер солит профилем, поэтому выбор, сделанный в Chrome, во встроенном браузере OBS
указывал бы в пустоту, и запрос камеры падал бы с `OverconstrainedError`. Если камеры
с таким названием на второй стороне нет, она просто берёт камеру по умолчанию.

**Яркость** — это и есть регулятор «светлее/темнее». Порога в настройках нет
намеренно: у Флойда–Стайнберга ошибка растекается по соседним точкам, и доля чёрного
в кадре повторяет среднюю яркость, а не порог, — двигать порог бессмысленно.

**Зеркало** по умолчанию выключено: собеседник видит вас как в жизни, а не отражённым.

**Размер точки** заметно влияет на нагрузку: кадр считается в уменьшенном масштабе
и растягивается обратно. По умолчанию точка 1 — самая мелкая и самая тяжёлая:
на 1280 × 720 это 921 600 пикселей на кадр, точка 2 — вчетверо меньше.
Если fps в панели проседает, увеличьте точку.

**Разрешение** в режиме источника задаёт не размер кадра, а размер окна: кадр всегда
считается ровно по окну, чтобы при захвате не появились чёрные поля.

## Как устроен кадр

```
камера → центральный кроп под 16:9 → маски поверх видео → grayscale + контраст
       → Флойд–Стайнберг → канвас → OBS → виртуальная камера
```

Маски ложатся **до** бинаризации: иначе они были бы гладкими картинками поверх
дизеренного лица и выпадали бы из стиля.

| Файл | Что делает |
| --- | --- |
| `public/js/pipeline.js` | цикл кадра, камера, кроп |
| `public/js/ditherer.js` | grayscale → контраст → Флойд–Стайнберг |
| `public/js/faceLandmarker.js` | детектор лица MediaPipe |
| `public/js/faceTracks.js` | сглаживание поз и сшивание лиц между кадрами |
| `public/js/maskPainter.js` | отрисовка масок по позе |
| `public/js/maskCatalog.js` | посадка масок: якорь, ширина, сдвиг |
| `public/js/slotMachine.js` | рулетка |
| `public/js/state.js`, `server.js` | общее состояние панели и OBS |

Модель и wasm лежат локально и раздаются своим же сервером: OBS пересоздаёт страницу
при каждом перезапуске источника, и тянуть 4 мегабайта с CDN на каждый запуск — это
пауза перед первой маской. Заодно фильтр работает без интернета.

## Добавить свою маску

Положить PNG в `public/masks/<категория>/` и перезагрузить страницу. Категории:
`glasses`, `headwear`, `mustaches`, `mouths` — от категории зависит, к какой точке
лица маска крепится.

PNG должен быть обрезан по содержимому: посадка считается от краёв картинки.
Если маска села не так, поправить её одним числом в `placementOverrides`
в `public/js/maskCatalog.js`.

## Ограничения

- Кадры рисует браузер, поэтому вкладка панели в фоне замирает. Для OBS это неважно:
  он держит свою страницу живой сам.
- Детектор ищет до трёх лиц одновременно.
- Пока ни одна маска не выбрана, детектор не запускается — процессор не греется зря.
